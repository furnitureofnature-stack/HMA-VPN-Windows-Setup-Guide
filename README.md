### ⚡ One-Click Connection Flow
The main window presents a single prominent control that begins the connection sequence. Behind the scenes, the utility evaluates server availability, negotiates the handshake, and confirms the tunnel state — but from your perspective, there is only one button to press and one status light to watch.

### 🔄 Automatic Server Rotation
For users who prefer their sessions to wander the globe, an optional rotation mode reassigns the exit node at configurable intervals. This is useful for testing how services behave across regions, or simply for adding a layer of unpredictability to one's browsing pattern.

### 🧩 Split Tunneling Controls
Not every application needs to travel the same road. The split tunneling panel lets you designate which programs bypass the encrypted tunnel and which ones are required to use it. This is a game-changer for local file transfers, LAN printers, and latency-sensitive games that prefer the shortest path.

### 🛡️ Kill Switch Mechanism
If the tunnel ever drops unexpectedly, the kill switch halts outbound traffic from the designated applications until the connection is restored. Think of it as a seatbelt that tightens automatically the moment the road gets rough.

### 📊 Live Connection Statistics
A compact dashboard displays session duration, data transferred, current exit region, and protocol in use. The statistics refresh at a readable cadence — fast enough to be useful, slow enough to avoid visual noise.

### 🧠 Adaptive Protocol Selection
The software can choose between available tunneling protocols based on network conditions, favoring stability on flaky Wi-Fi and speed on wired connections. Manual override is always available for users who know exactly what they want.

### 🗂️ Profile Management
Save multiple configuration profiles for different contexts — one for home, one for travel, one for the coffee shop down the street. Switching between profiles takes a single click and restores every associated preference.

### 🔔 Notification Center
Discreet system tray notifications keep you informed about connection state changes, without resorting to pop-up windows that steal focus. You decide which events deserve a nudge and which should remain silent.

## 🛠️ Configuration Notes

The settings panel is organized into four tabs: Connection, Privacy, Appearance, and Advanced. Each tab groups related controls so that adjustments feel like tuning a single instrument rather than editing a sprawling registry.

The **Connection** tab governs protocol preference, auto-connect behavior, and server rotation intervals. The **Privacy** tab houses the kill switch, DNS leak protection, and split tunneling rules. The **Appearance** tab controls theme (light, dark, or system), accent color, and interface density. The **Advanced** tab exposes logging verbosity, diagnostic exports, and experimental features that are still under evaluation.

Profiles are stored locally and can be exported for backup purposes. Each profile captures the full state of every tab, so restoring a configuration is as simple as selecting it from the profile list.
